# Selvi Grup – Web Sitesi

**Selvi Grup** (Kartal, İstanbul) kurumsal web sitesinin kaynak dosyaları.

🌐 Canlı site: **https://www.selvigrup.com**

## İçerik

- `index.html` – Tek sayfalık site (Türkçe / İngilizce dil desteği)
- `assets/` – Logo, ikonlar, paylaşım görseli
- `assets/img/` – Proje, galeri ve iç mekân fotoğrafları
- `robots.txt`, `sitemap.xml` – Arama motorları için

Site sadece HTML, CSS ve JavaScript'ten oluşur; derleme (build) adımı ya da sunucu tarafı kod gerekmez.

## Yayın

Site [Netlify](https://www.netlify.com) üzerinde barındırılır, alan adı GoDaddy'de kayıtlıdır.
Güncellemek için klasörü Netlify'da projenin **Deploys** sayfasına sürükleyip bırakmak yeterlidir.

## Yerelde açmak

`index.html` dosyasını tarayıcıda açmanız yeterlidir.
